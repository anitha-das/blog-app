# Blog Application – MERN Stack

A full-stack Blog Application built using the **MERN Stack** where users can register either as a **User** or an **Author**.

The application provides authentication, role-based access, article publishing, article reading, and commenting features with a clean and responsive user interface.

---

# Features

## User Features

* User Registration and Login
* Read Published Articles
* View Detailed Article Pages
* Add Comments on Articles
* Responsive User Interface

## Author Features

* Register as Author
* Secure Login Authentication
* Create and Publish Articles
* Edit Existing Articles
* Manage Published Articles

## Admin Features

* Manage Users and Authors
* Protected Admin Routes
* Role-Based Access Control

# Application Workflow

* Users can register either as User or Author
* Authentication is handled securely using JWT
* Role-based navigation is implemented
* Authors can create and manage articles
* Users can read and comment on articles
* Protected routes restrict unauthorized access

---

# Architecture Overview

The application follows a component-based architecture with separate dashboards and functionalities for Users, Authors, and Admins.

The frontend communicates with backend REST APIs for authentication, article management, and user operations.

MongoDB is used for storing user data, articles, and comments.
